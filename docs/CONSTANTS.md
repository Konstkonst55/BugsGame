# BugsGame – константы и параметры

Справочник основных игровых, расчётных и технических констант проекта. Значения сгруппированы по назначению; единицы измерения указаны в названиях или описаниях.

## Регистрация и настройки

| Константа                        | Значение | Описание                                         |
| -------------------------------- | -------: | ------------------------------------------------ |
| `MIN_DIFFICULTY`                 |      `1` | Минимальный уровень сложности профиля            |
| `DEFAULT_DIFFICULTY`             |      `2` | Уровень сложности по умолчанию                   |
| `MAX_DIFFICULTY`                 |      `3` | Максимальный уровень сложности профиля           |
| `MIN_SPEED`                      |      `1` | Минимальная ручная скорость                      |
| `DEFAULT_SPEED`                  |      `5` | Скорость по умолчанию                            |
| `MAX_SPEED`                      |     `10` | Максимальная ручная скорость                     |
| `MIN_MAX_COCKROACHES`            |      `1` | Минимальное количество обычных насекомых на поле |
| `DEFAULT_MAX_COCKROACHES`        |      `3` | Максимальное количество по умолчанию             |
| `MAX_MAX_COCKROACHES`            |     `10` | Верхняя граница количества обычных насекомых     |
| `MIN_BONUS_INTERVAL_SECONDS`     |      `5` | Минимальный интервал появления бонуса            |
| `DEFAULT_BONUS_INTERVAL_SECONDS` |     `15` | Интервал появления бонуса по умолчанию           |
| `MAX_BONUS_INTERVAL_SECONDS`     |     `60` | Максимальный интервал появления бонуса           |
| `MIN_ROUND_DURATION_SECONDS`     |     `30` | Минимальная длительность раунда                  |
| `DEFAULT_ROUND_DURATION_SECONDS` |     `60` | Длительность раунда по умолчанию                 |
| `MAX_ROUND_DURATION_SECONDS`     |    `300` | Максимальная длительность раунда                 |

## Расчёт итоговых очков

| Константа                  | Значение | Описание                                                     |
| -------------------------- | -------: | ------------------------------------------------------------ |
| `PENALTY_COST`             |    `1.5` | Вычитается из набранных очков за каждый промах               |
| `AVERAGE_BUG_POINTS`       |    `2.0` | Средняя оценка очков за одно ожидаемое появление насекомого  |
| `MAX_PERFORMANCE`          |    `1.4` | Верхнее ограничение коэффициента эффективности раунда        |
| `BASE_SCORE`               |    `500` | Базовый множитель итоговой формулы                           |
| `MIN_SCORE`                |      `0` | Минимальный итоговый результат                               |
| `MAX_SCORE`                |   `1000` | Максимальный итоговый результат                              |
| `DIFFICULTY_EASY_FACTOR`   |    `0.9` | Множитель сложности 1                                        |
| `DIFFICULTY_NORMAL_FACTOR` |    `1.0` | Множитель сложности 2                                        |
| `DIFFICULTY_HARD_FACTOR`   |    `1.1` | Множитель сложности 3                                        |
| `MIN_SPEED_FACTOR`         |   `0.85` | Нижняя граница множителя скорости                            |
| `MAX_SPEED_FACTOR`         |   `1.15` | Верхняя граница множителя скорости                           |
| `MIN_MAX_BUGS_FACTOR`      |    `0.9` | Нижняя граница множителя максимального количества насекомых  |
| `MAX_MAX_BUGS_FACTOR`      |    `1.1` | Верхняя граница множителя максимального количества насекомых |
| `MIN_DURATION_RATIO`       |    `0.5` | Нижняя граница отношения длительности к стандартной          |
| `MAX_DURATION_RATIO`       |    `2.0` | Верхняя граница отношения длительности к стандартной         |
| `MIN_DURATION_FACTOR`      |   `0.75` | Нижняя граница множителя длительности                        |
| `MAX_DURATION_FACTOR`      |   `1.25` | Верхняя граница множителя длительности                       |

Стандартная длительность для нормализации – `60` секунд; стандартный интервал появления для базового ожидаемого количества – `900` мс. Эти значения используются непосредственно в расчёте `CalculateRoundScoreUseCase`.
